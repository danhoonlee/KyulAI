# ImperialAX 홈페이지 사업·고객·목표 브리프

작성일: 2026-08-11

용도: Sites 기반 ImperialAX 기업 홈페이지 제작 시 초기 질문 답변과 콘텐츠 기획의 기준 자료.

## 1. 어떤 사업을 운영하시나요?

ImperialAX는 제조·복합재 엔지니어링 분야의 CAE 해석 데이터를 AI 예측과 설계 의사결정 도구로 전환하는 B2B 엔지니어링 소프트웨어 기업입니다. 복잡하고 반복적인 시뮬레이션을 무조건 대체하기보다, 상세 해석 전에 많은 설계 후보를 빠르게 선별하고 결과의 의미를 이해하며 최종 검증 대상을 정할 수 있도록 지원합니다.

주요 제품과 서비스는 다음과 같습니다.

### ImperialAX Laminate Forecast

복합재, 특히 Double-Double 적층 구조의 설계를 지원하는 AI 예측 솔루션입니다. 적층 Case와 두 개의 각도 값을 입력하면 응답 Type, 전이하중 Pt, Force–Displacement 곡선, 최대 하중·변위, u3 거동 등을 예측합니다. CLT 기반 물리 feature와 XAI를 함께 제공하여 어떤 적층 특성이 결과에 영향을 주었는지 설명하고, 유망한 후보를 Abaqus 등의 상세 구조해석 전에 선별하도록 돕습니다.

### ImperialAX Injection Forecast

사출성형 형상과 공정 조건을 바탕으로 Sprue Pressure 곡선과 Filling Pressure 특성을 빠르게 예측하는 AI 솔루션입니다. Moldex3D 해석 데이터로 학습한 surrogate model을 이용해 형상·공정 조합을 비교하고, 압력 변화와 주요 결과를 차트와 시각화로 확인할 수 있도록 지원합니다.

### ImperialAX AI Workspace

Laminate와 Injection을 하나의 계정과 모듈형 화면에서 이용할 수 있도록 통합하는 웹·모바일 제품 방향입니다. 향후 새로운 CAE-AI 모델, 예측 이력, 보고서, 공유, 라이선스와 모듈 접근 관리 기능을 하나의 플랫폼으로 확장하는 것을 목표로 합니다.

### 프로젝트형 지원

고객이 보유한 CAE·시험 데이터를 바탕으로 데이터 구조화, 예측 대상 정의, surrogate model 개발, XAI, 검증 체계와 PoC를 함께 설계하는 프로젝트형 기술 지원으로 확장할 수 있습니다. 다만 홈페이지에서는 실제 제공 범위가 확정된 항목만 서비스로 표시하고, 그 외에는 ‘기술 상담’ 또는 ‘PoC 협의’로 표현하는 것이 안전합니다.

## 2. 핵심 고객은 누구인가요?

ImperialAX의 핵심 고객은 개인 소비자가 아니라 CAE 해석과 제품 설계를 수행하는 기업·연구기관의 엔지니어링 조직입니다.

- 주요 사용자: CAE 엔지니어, 구조·복합재 엔지니어, 사출성형·공정 엔지니어, AI/ML 연구원, 시험·검증 담당자
- 주요 의사결정자: R&D 책임자, 해석팀장, 디지털 전환·AI 담당자, 기술개발 임원, 연구과제 책임자
- 주요 업종: 항공·우주 복합재, 모빌리티와 고성능 구조물, 복합재 패널 개발, 사출성형 제품·금형·공정 개발, 산업용 CAE 소프트웨어 활용 조직
- 주요 지역: 한국 기업과 연구기관을 우선 대상으로 하되, 영문 기술 콘텐츠와 웹 기반 데모를 통해 해외 엔지니어링 조직으로 확장 가능한 B2B 구조

고객이 겪는 대표적인 문제는 다음과 같습니다.

- 설계변수와 조합이 많아 모든 후보를 상세 CAE로 계산하기 어렵다.
- 반복 해석에 시간과 계산 자원이 많이 들고, 결과 비교도 수작업에 의존한다.
- 기존 해석 데이터가 축적되어 있지만 다음 설계 판단에 충분히 재사용되지 않는다.
- AI 예측값만 제시하면 엔지니어가 신뢰하거나 설계 근거로 활용하기 어렵다.
- 모델의 적용 범위, 불확실성, OOD 여부와 최종 검증 절차가 명확해야 한다.
- CAE 도구, 데이터, 모델, 보고서가 분리되어 운영 흐름이 끊긴다.

## 3. 웹사이트가 고객에게 어떤 도움을 줘야 하나요?

홈페이지의 가장 중요한 역할은 방문자가 1분 안에 ‘ImperialAX가 어떤 엔지니어링 문제를 해결하며, 왜 기존 CAE 업무에 도움이 되는지’를 이해하도록 만드는 것입니다.

### 서비스 이해

- ImperialAX가 CAE를 대체하는 블랙박스 AI가 아니라 ‘후보 선별 → 판단 → 상세 해석·시험 검증’을 빠르게 연결하는 도구임을 설명합니다.
- Laminate와 Injection을 명확히 분리해 각 제품의 입력, 출력, 사용 흐름과 적용 분야를 보여줍니다.
- 예측 Type, Pt, 압력 곡선, XAI 등 어려운 용어는 엔지니어가 업무 효과와 연결해 이해할 수 있도록 설명합니다.

### 신뢰 형성

- 실제 제품 화면, 차트, 사용 시나리오와 데모를 보여줍니다.
- 학습·검증 범위, 적용 가능한 Case·형상·공정 조건, 데이터 한계와 최종 CAE 검증 필요성을 정직하게 표시합니다.
- 단순 정확도 숫자보다 설계 후보를 얼마나 줄이고, 어떤 근거로 결과를 설명하며, 검증 흐름을 어떻게 연결하는지를 보여줍니다.
- 기술 문서, 연구 결과, 적용 사례와 보안·데이터 처리 원칙을 제공하여 엔지니어링 조직의 검토를 돕습니다.

### 전환과 문의

고관여 B2B 엔지니어링 제품이므로 온라인 결제보다 다음 행동을 우선하는 것이 적합합니다.

1. 제품 데모 체험
2. 기술 상담 신청
3. PoC 또는 맞춤 모델 가능성 검토
4. 견적 요청
5. 기술자료·소개서 다운로드

문의 양식에는 회사명, 업종, 담당 업무, 사용 중인 CAE 도구, 해결하려는 문제, 보유 데이터 종류와 규모, 희망 연락 방법을 받는 것이 좋습니다.

## Sites 입력용 짧은 답변

### 어떤 사업을 운영하시나요?

ImperialAX는 제조·복합재 분야의 CAE 해석 데이터를 AI 예측과 설계 지원 도구로 전환하는 B2B 엔지니어링 소프트웨어 기업입니다. 주요 제품은 Double-Double 복합재의 응답 Type, 전이하중 Pt와 하중–변위 곡선을 예측하는 **Laminate Forecast**, 사출성형 형상·공정 조건으로 Sprue 및 Filling Pressure를 예측하는 **Injection Forecast**입니다. AI가 상세 시뮬레이션을 완전히 대체하기보다, 많은 설계 후보를 빠르게 선별하고 XAI로 판단 근거를 제공한 뒤 유망 후보를 CAE와 시험으로 검증하도록 돕습니다.

### 핵심 고객은 누구인가요?

주요 고객은 CAE 해석과 제품 설계를 수행하는 기업 및 연구기관입니다. 핵심 사용자는 구조·복합재·사출성형 엔지니어, CAE 담당자, AI/ML 연구원과 시험·검증 담당자이며, R&D 책임자와 디지털 전환 담당자가 주요 의사결정자입니다. 이들은 설계 조합이 많아 반복 해석 비용이 크고, 축적된 해석 데이터를 재활용하기 어려우며, AI 예측의 근거·적용 범위·검증 절차까지 확인해야 하는 문제를 겪습니다. 초기에는 한국의 제조·복합재·연구 조직을 중심으로 하되 해외 엔지니어링 고객까지 확장할 수 있습니다.

### 웹사이트가 고객에게 어떤 도움을 줘야 하나요?

웹사이트는 방문자가 ImperialAX의 제품과 기술적 차별점을 빠르게 이해하고 신뢰할 수 있도록 해야 합니다. 제품별 입력·출력·업무 효과, 실제 화면과 예측 결과, XAI, 적용 범위와 한계를 명확히 보여주고, ‘후보 선별 → 엔지니어 판단 → 상세 CAE·시험 검증’의 흐름을 설명해야 합니다. 핵심 전환 목표는 온라인 구매보다 **제품 데모 체험, 기술 상담, PoC 협의와 견적 요청**이며, 기술자료와 사례를 통해 기업 고객의 내부 검토를 돕는 것이 중요합니다.

- 보조 문구: **CAE 해석 데이터를 빠른 예측, 설명 가능한 판단, 검증 가능한 설계 흐름으로 연결합니다.**
- Laminate 문구: **복합재 적층 후보를 빠르게 예측하고, 물리 기반 XAI로 설계 판단을 지원합니다.**
- Injection 문구: **형상과 공정 조건에서 압력 응답을 예측해 사출 설계 탐색을 가속합니다.**
- 주요 CTA: **제품 데모 보기 / 기술 상담 신청 / PoC 문의**

## 표현상 주의사항

- ‘CAE 해석을 대체한다’고 표현하지 않습니다. 유망 후보 선별과 의사결정 지원으로 설명합니다.
- 현재 검증된 데이터 범위 밖의 재료·형상·공정을 모두 지원한다고 주장하지 않습니다.
- 모델 성능 수치는 데이터 분할과 검증 조건을 함께 제시할 수 있을 때만 사용합니다.
- 프로젝트형 개발, 컨설팅, 데이터 보안 정책은 실제 계약·운영 범위가 확정된 항목만 공개 서비스로 표시합니다.
