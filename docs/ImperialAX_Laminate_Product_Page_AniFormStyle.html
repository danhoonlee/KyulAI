ImperialAX Laminate Forecast

ImperialAX Laminate Forecast는 복합재 적층 구조, 특히 Double-Double Laminate의 Type, 전이하중 Pt, Force-Displacement 응답 곡선, u3 거동을 빠르게 예측하기 위한 AI 기반 설계 지원 솔루션입니다.

사용자는 적층 Case와 두 개의 각도 값 θ₁, θ₂를 입력하는 것만으로 상세 CAE 해석 전에 유망한 적층 후보를 선별하고, Physics XAI를 통해 왜 이런 예측이 나왔는지까지 함께 검토할 수 있습니다.

Positioning

본 솔루션은 최종 구조 검증을 대체하는 도구가 아니라, 많은 적층 후보 중 상세 해석으로 넘길 대상을 빠르게 압축하는 AI/CAE 선별 도구입니다. 유망 후보는 반드시 상세 CAE 해석 및 실험 검증과 함께 판단해야 합니다.

AI-based laminate screening
Case와 θ 입력만으로 적층 후보를 빠르게 선별

기존 복합재 적층 설계에서는 각도와 적층 순서 조합이 많아 반복 해석 비용이 커집니다. ImperialAX Laminate Forecast는 축적된 해석 데이터와 물리 기반 feature를 활용해, 상세 해석 전에 유망 후보를 빠르게 좁히는 워크플로우를 제공합니다.

Integrated forecast workspace

  • 연구 목적, 입력 설정, 예측 결과, XAI, Assistant를 하나의 화면에서 확인
  • Case와 θ₁, θ₂를 입력해 Type, Pt, 곡선, u3 거동을 빠르게 검토
  • 웹 기반 화면으로 연구자와 엔지니어가 같은 결과를 공유 가능

Simple Case and angle input

  • θ₁, θ₂ 각도를 입력하거나 슬라이더로 조정
  • Machine Learning과 Deep Learning 모델을 비교 검토

Prediction summary

  • 입력값, 모델명, 예측 신뢰도, 주요 결과를 한 번에 확인
  • 제품 데모나 연구 회의에서 바로 공유 가능한 결과 화면 제공
Response curve and transition load prediction
Force-Displacement 곡선과 Pt를 예측

Laminate Forecast는 단순히 Type만 분류하지 않고, 응답 곡선과 전이하중 Pt를 함께 예측합니다. Pt는 곡선의 knee 또는 transition point를 의미하며, 적층 구조의 안정성 변화가 시작되는 하중 수준을 후보별로 비교하는 데 활용됩니다.

Predicted curve with Pt

  • Force-Displacement 예측 곡선 표시
  • bilinear fitting line과 예측 Pt를 함께 시각화
  • 최대 하중, 최대 변위, Pt 값을 카드 형태로 정리

Supported stacking cases

Case 2
[[±θ₁]/[±θ₂]]₄
Case 3
[[±θ₁]/ [±θ₂]/ [∓θ₂]/ [∓θ₂]]₂
Case 4
[([±θ₁]/ [±θ₂])₂ / ([∓θ₁]/ [∓θ₂])₂]
  • 현재 학습/검증 데이터는 Case 2, Case 3, Case 4를 중심으로 구성
  • 새로운 적층 패턴은 실제 ply sequence로 전개 후 물리 feature 계산을 통해 확장 가능
  • 후보 적층은 최종 설계 전 상세 CAE 해석으로 재검증 권장
Physics XAI
D11, A11, A12, D66 등 물리 feature 기반 설명

AI 예측 결과는 값만으로는 설계 판단에 충분하지 않습니다. ImperialAX Laminate Forecast는 Classical Laminate Theory 기반 feature와 XAI를 결합하여, 어떤 물리 인자가 현재 예측에 크게 작용했는지 보여줍니다.

Feature influence

  • D11 굽힘 강성, A11 막 강성, D66 비틀림 강성 등 주요 feature 영향도 표시
  • 각 feature가 무엇을 의미하는지 한국어 설명 제공
  • 현재 입력값 기준 local sensitivity와 feature masking 결과를 함께 제공

CLT-based descriptors

  • 입력된 Case와 θ₁, θ₂를 실제 ply sequence로 전개
  • T800/3900S 재료 물성과 ply thickness를 바탕으로 ABD matrix 계산
  • A/h, 2B/h², 12D/h³ 기준 normalized ABD feature 사용
  • membrane stiffness, bending stiffness, bend-twist coupling, anisotropy descriptor 포함
Design-space insight and recommendation
현재 입력 위치, Case별 영역, 추천 후보를 함께 검토

Design-space map은 기존 해석 데이터 공간에서 현재 입력값이 어디에 위치하는지 보여줍니다. 이를 통해 예측 결과의 신뢰도, 가까운 해석 데이터, Type 분포, 추천 후보를 함께 검토할 수 있습니다.

Design-space map

  • Type별 데이터 포인트와 현재 입력 위치 표시
  • 가까운 기존 해석 데이터와 추천 후보 확인
  • Case별 상위 Pt Type 1 영역과 위험도 정보를 함께 제공

Engineering decision support

  • 현재 후보와 추천 후보의 Pt, Type, Case 위험도를 비교
  • 해석 데이터 coverage와 interpolation/extrapolation 상태를 검토
  • 상세 해석으로 넘길 후보를 빠르게 선정하는 의사결정 보조
u3 Forecast
u3 변위 관점의 Pt와 곡선 거동 예측

Type 2와 Type 3처럼 knee 이후 곡률이 커지는 경우에는 force-displacement 응답만으로 판단하기 어려울 수 있습니다. u3 Forecast는 변위 기반 거동을 추가로 예측하여 적층 후보를 다른 관점에서 검토할 수 있게 합니다.

u3 result summary

  • u3 Type, Pt, 최대 변위/하중을 예측
  • Laminate Forecast와 별도 모델로 변위 거동을 검토
  • ML/DL 모델을 함께 운용하여 비교 가능

u3 curve visualization

  • u3 기반 곡선과 transition point 표시
  • 응답 곡선과 함께 적층 안정성 변화를 비교
  • 복합재 패널의 변위 민감 후보를 사전에 확인
