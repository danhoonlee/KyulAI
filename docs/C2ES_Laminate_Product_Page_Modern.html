Why it matters

반복 해석 전에 유망 적층 후보를 먼저 좁힙니다

복합재 적층 설계에서는 Case, θ₁, θ₂ 조합에 따라 Force-Displacement 응답과 전이하중 Pt가 크게 달라집니다. 모든 후보를 상세 해석으로 확인하면 시간이 많이 들기 때문에, Laminate Forecast AI는 축적된 해석 데이터와 Classical Laminate Theory 기반 물리 feature를 활용해 설계 초기 후보 선별 속도를 높이는 데 초점을 둡니다.

적층 Type 예측 Type 1, Type 2, Type 3 응답 형태를 확률과 함께 표시합니다.
Pt 및 곡선 예측 전이하중 Pt와 Force-Displacement 응답 곡선을 함께 제공합니다.
설명 가능한 AI D11, D66, A11, 각도 분포 등 주요 영향 인자를 확인합니다.

Double-Double 적층 패턴

현재 모델은 연구 데이터가 구축된 Case 2, Case 3, Case 4를 중심으로 학습되어 있습니다. 각 Case는 θ₁, θ₂ 조합이 실제 ply sequence로 전개된 뒤, 물리 feature와 함께 예측에 사용됩니다.

Case 2 [[±θ₁]/[±θ₂]]₄
Case 3 [[±θ₁]/[±θ₂]/[∓θ₂]/[∓θ₂]]₂
Case 4 [([±θ₁]/[±θ₂])₂ / ([∓θ₁]/[∓θ₂])₂]
입력부터 결과까지의 워크플로우 Case 선택, 각도 입력, 예측 실행, XAI 검토를 한 흐름으로 구성합니다.

Workflow

입력부터 해석 설명까지 한 흐름으로 구성

01 Case 선택

Case 2, Case 3, Case 4 적층 패턴을 선택합니다.

02 각도 입력

θ₁, θ₂ 값을 입력하거나 슬라이더로 조정합니다.

03 예측 실행

Type, Pt, 곡선, 신뢰도 정보를 빠르게 계산합니다.

04 XAI 검토

결과에 영향을 준 물리 feature와 설계 위치를 확인합니다.

Forecast setup과 예측 결과 각도 반영 ply stack 미리보기와 Prediction result 화면을 함께 보여줍니다.

Forecast setup

각도 입력과 실시간 ply stack 미리보기

사용자는 Case와 θ₁, θ₂만 입력해 상세 해석 전 후보 적층의 응답을 빠르게 확인할 수 있습니다. 입력한 각도는 오른쪽의 ply stack 미리보기에 바로 반영되어, 현재 조합이 실제 적층 형상으로 어떻게 전개되는지 함께 볼 수 있습니다.

  • Case 2, Case 3, Case 4 적층 패턴 지원
  • θ₁, θ₂ 직접 입력 및 슬라이더 조정
  • 각도 조합에 따라 바뀌는 ply stack을 실시간 확인

Prediction result

예측 결과 화면

Response curve와 Pt 예측 Force-Displacement curve, bilinear fitting line, Pt 위치를 확인합니다.

Response curve

Pt와 곡선 형태를 함께 보는 예측

Laminate Forecast AI는 Type만 분류하지 않고, 전이하중 Pt와 응답 곡선까지 함께 예측합니다. 곡선 위에는 bilinear fitting line과 Pt 위치가 표시되어, 후보 적층의 stiffness 변화 지점을 직관적으로 비교할 수 있습니다.

  • Force-Displacement surrogate curve 표시
  • 두 개의 linear fitting line으로 knee point 확인
  • 상세 해석 전 후보 간 응답 수준 비교
Physics XAI와 Design-space insight 예측 근거 feature와 현재 입력의 실험 공간 위치를 함께 검토합니다.

Physics XAI

예측값의 근거가 된 물리 feature를 확인

설계자가 신뢰할 수 있는 AI가 되려면 결과값뿐 아니라 왜 그런 예측이 나왔는지도 확인할 수 있어야 합니다. Laminate Forecast AI는 θ 정보뿐 아니라 CLT 기반 stiffness, coupling, anisotropy feature를 함께 사용하고, 예측에 크게 작용한 feature를 퍼센트 형태로 보여줍니다.

  • D11, D66, A11 등 stiffness descriptor 표시
  • θ 조합, 최소/최대 절대각, 적층 균형성 영향 확인
  • Tree 기반 XAI와 GointMLP-style DL XAI 모델 구성

Design-space insight

현재 입력이 전체 실험 공간에서 어디에 있는지 확인

Design-space map은 기존 실험 데이터와 현재 입력, 추천 후보를 함께 보여줍니다. Case별 Type 분포와 위험 영역을 보면서 현재 조합이 보간 영역에 있는지, 혹은 데이터가 부족한 영역에 가까운지 판단할 수 있습니다.

  • Type별 색상 분포와 현재 입력 위치 표시
  • Top candidate와 현재 입력 비교
  • Reliability, coverage, Type agreement 등 연구자용 지표 제공

AI Assistant

예측 결과를 설명하는 RAG 기반 Assistant

Laminate AI Assistant는 연구 PPT, 내부 리포트, 모델 XAI 결과, 복합재 적층 관련 지식을 함께 검색하여 현재 예측 결과를 문장으로 설명합니다. 단순 Q&A가 아니라, 사용자가 방금 실행한 prediction context를 참고해 D11, D66, A11, Case 식, Type 분포와 같은 정보를 연결해 설명하도록 구성되어 있습니다.
