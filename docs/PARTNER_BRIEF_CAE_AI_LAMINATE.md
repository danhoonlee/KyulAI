## 슬라이드 1 — 한 줄 요약

> **유한요소해석을 매번 돌리지 않고, 복합재 라미네이트의 하중-변위 거동과 전이하중(Pt)을
> 설계 단계에서 즉시 예측한다.**

핵심은 "빠르다"가 아니라 **"설계 공간 전체를 훑을 수 있다"** 는 것이다.
해석 한 건을 아끼는 게 아니라, 원래는 시도조차 못 하던 탐색을 가능하게 한다.

---

## 슬라이드 2 — 왜 이 문제인가

복합재 적층 설계는 **조합 폭발** 문제다.

- 전통적 quad 적층(0/±45/90)은 각도 선택지가 고정되어 있고, 설계 자유도가 적층 순서에 갇힌다.
- **Double-Double(DD)** 은 `[±θ₁/±θ₂]` 두 쌍의 블록을 반복하는 방식이다.
  θ₁, θ₂가 연속 변수이므로 설계 공간이 이산 조합에서 **연속 2차원 평면**으로 바뀐다.
- 자유도가 늘어난 만큼, 어디가 좋은 영역인지 사람이 직관으로 짚기 어려워진다.

DD의 공학적 이점은 문헌에 정리되어 있다. 이 연구가 더하는 것은
**"그 넓어진 공간에서 어디를 골라야 하는가"** 에 대한 답이다.

---

## 슬라이드 3 — 무엇을 예측하는가: 전이하중 Pt

이 부분이 협력사에 가장 정확히 전달되어야 한다. **최대하중이 아니라 전이하중이 목표다.**

- 시험/해석 조건에서 **변위가 0.15 in로 고정**되어 있다. 따라서 "최대하중"은 사실상
  스트로크 끝점의 하중값이다. 샘플 180건 전수 확인 결과 **180건 모두** 최대값이 곡선 끝에 있었다.
- 설계상 의미 있는 값은 **재료가 변형 거동을 바꾸기 시작하는 지점**, 즉 전이하중 Pt다.
- Pt를 기준으로 곡선이 좌/우로 나뉘며, **양쪽이 모두 선형에 가까울수록 좋은 설계**다.

### 거동 유형 (Type)

| Type | 곡선 형상 | 의미 |
|---|---|---|
| **Type 1** | 명확한 bilinear. 전이 전후 모두 선형 | **설계 요구조건을 만족** |
| Type 2 | 전이 이후 구간이 휘어짐 | 조건부 |
| Type 3 | 전반적으로 크게 휘어짐 | 부적합 |

Type은 3-class 분류 문제가 아니라 **bilinear 기술(description)이 얼마나 잘 성립하는가의 등급**이다.

### 왜 좌굴하중이 아니라 전이하중인가

비대칭 적층에서는 B 행렬이 0이 아니어서 막-굽힘 연성이 발생한다.
선형 고유값 좌굴해석은 이 경우 **사용 가능 하중을 과대평가**한다.
따라서 기하 결함(imperfection)을 씨딩한 비선형 정적해석에서 전이하중을 읽는 것이 실제 거동에 가깝다.

## 슬라이드 5 — 파이프라인

```
[1] 고충실도 해석          Abaqus 비선형 정적, 결함 씨딩
        ↓                  2,700건 × 1,001점
[2] 물리 기반 피처          CLT A/B/D 행렬, 두께 정규화,
        ↓                  적층 이방성/대칭성 기술자, 패널 기하
[3] 대리모델               Tree / GointMLP / Hybrid Student
        ↓                  Type + Pt + 곡선 전체를 동시 출력
[4] 설계 공간 탐색          제약(Type 1) 내 순위화, 신뢰도 동반
        ↓
[5] 서비스                 REST API + 웹 UI, 실시간
```

**2단계가 핵심이다.** θ₁, θ₂를 그대로 넣지 않고 고전적층이론(CLT)으로 재인코딩한다.
정량적으로 확인한 효과:

| 입력 | Pt MAE | Type 1 구간 Pt MAE | Type 정확도 |
|---|---:|---:|---:|
| θ₁, θ₂, case, 패널 (원시 입력) | 467.17 | 643.12 | 0.8962 |
| **CLT 물리 피처 (40열)** | **200.79** | **176.93** | **0.9581** |

물리를 좌표계로 넣는 것만으로 **Pt 오차 2.3배, 설계 유효 구간에서 3.6배** 개선된다.

## 슬라이드 7 — 방법론적 차별점 (여기에 시간을 쓸 것)

이 부분이 협력사가 "제대로 하고 있는가"를 판단하는 지점이다.
숫자보다 **숫자를 믿을 수 있게 만든 장치**가 설득력이 크다.

### (1) 학습 없는 베이스라인을 상시 비교 대상으로 둔다

리포트에 **"최근접 조회"** 행이 영구 고정되어 있다. 학습을 전혀 하지 않고,
홀드아웃 각 행을 각도 공간에서 가장 가까운 학습 행으로 답하는 방식이다.

> **이 행을 명확히 이기지 못한 모델은 일반화가 증명되지 않은 것이다.**

실제로 이 장치가 문제를 잡아냈다. 초기 분할은 `case + θ₁ + θ₂`를 키로 썼는데,
Case2/3/4는 같은 설계의 블록 순열이라 사실상 같은 라미네이트다
(설계점 고정 시 Case 간 Pt 중앙값 차이 0.14%).
그 결과 홀드아웃 546행 중 **537행이 학습셋에 같은 각도 쌍 쌍둥이를 갖고 있었고**,
조회 테이블이 모든 학습 모델을 이겼다.
분할 키를 각도 쌍만으로 교정한 뒤에야 위의 성능이 나왔다. 회귀 테스트로 고정해 두었다.

### (2) 요구조건과 목적함수를 분리한다

Type 1은 "점수에 가중치로 반영할 선호"가 아니라 **충족해야 할 조건**이다.
Pt가 높다고 Type 3 설계가 수용 가능해지지 않는다.

```
maximize   Pt
subject to Type 1   (전이 전후 양쪽 선형)
```

따라서 API는 **먼저 조건을 만족하는 후보를 거르고, 그 안에서만 순위를 매긴다.**
조건을 만족하는 설계가 없으면 억지로 추천하지 않고 그렇다고 응답한다.

### (3) 유효 설계 비율을 함께 보고한다

| 패널 | 전체 | Type 1 충족 | 비율 |
|---|---:|---:|---:|
| 6×4 | 900 | 321 | **35.7%** |
| 6×8 | 900 | 227 | **25.2%** |
| 8×8 | 900 | 106 | **11.8%** |

**패널이 커질수록 쓸 수 있는 설계가 급격히 줄어든다.**
독립적인 곡선 형상 측정(Pt를 입력으로 쓰지 않고, 사람이 검토한 900건으로 캘리브레이션)으로
교차 확인한 결과 이 경향은 **라벨링 편향이 아니라 실제 물리**다.
(6×4 독립측정 35.6% vs 저장값 35.7%, 6×8 24.0% vs 25.2%)

이 숫자는 설계자에게 가장 먼저 필요한 정보다. 순위표보다 위에 표시한다.

### (4) 예측에 신뢰도를 동반한다

API 응답에 보간/외삽 판정, 인근 데이터 밀도, 국소 Pt 산포, Pt 구간 추정이 함께 나간다.
학습된 패널 범위(6–8 × 4–8 in) 밖 입력은 **차단**하고, 학습 데이터에 없는 패널 조합은
신뢰도를 상한 처리한다.

### (5) 피처 가설도 측정해서 기각한다

Double-Double 문헌의 표준 좌표(라미네이션 파라미터 ξA1·ξA2, trace 정규화)와
강성×치수 결합항을 추가 피처로 구현해 검증했다. **결과는 개선 없음**이었고,
그 음성 결과를 근거와 함께 기록해 두었다.
(트리 10시드·MLP 5시드 모두 동일 방향. `reports/dd_feature_redundancy/`)

이유도 규명했다. Tsai-Pagano 형식으로 전개하면
`A*₁₁ + A*₂₂ + 2A*₆₆ = 2(U₁+U₅)`, `A*₁₂ − A*₆₆ = U₄ − U₅` 로 **재료만의 함수**가 되며,
기존 피처가 이미 같은 정보를 담고 있었다. 재진술은 정보를 더하지 않는다.

## 슬라이드 9 — 확장 방향

### CAE-AI 플랫폼으로서

라미네이트는 **첫 번째 도메인**이다. 구조는 도메인 독립적이다.

```
고충실도 해석 → 물리 기반 피처 → 대리모델 → 제약 내 탐색 → 서비스
```

사출성형에 이미 같은 구조를 적용해 별도 서비스로 운영 중이다.
협력사의 해석 자산이 있다면 동일 파이프라인을 얹을 수 있다.

### 라미네이트 쪽 다음 단계

1. **오픈소스 솔버 연계 검증** — OpenRadioss 툴체인 구축 완료.
   최적화가 제안한 상위 설계를 독립 솔버로 교차 검증하는 루프.
2. **Case 확장** — 현재 Case2/3/4. PPT 기준 Case1/Case5까지 확장 여지.
3. **패널 범위 확장** — 현재 3종. 연속 패널 치수 대응.
4. **재료 확장** — 현재 단일 재료(T800/3900S). trace 정규화로 재료 간 전이 가능성.

## ⚠️ 발표 전 확인·보완 필요 (이 절은 슬라이드에 넣지 말 것)

작성 중 근거가 없어 **의도적으로 비워둔 항목들**이다. 채우거나 빼야 한다.

### 1. 해석 시간 대비 속도 이득 — 숫자 없음

"FE 대비 N배 빠름"은 가장 강력한 메시지지만, **Abaqus 해석 1건 소요시간이 기록에 없다.**
문서에 넣지 않았다. 실제 값을 아시면 슬라이드 1이나 6에 추가하면 좋다.

> 예: "해석 1건 약 O분 → 예측 0.4초"

근거 없이 배수를 쓰면 협력사가 검증할 때 바로 드러난다.

### 2. Pt 정의 일관성 — 진행 중 사안

6×4 데이터는 PPT의 P1 정의를, 6×8/8×8은 force-plot 꺾임점 정의를 따르고 있어
**두 정의가 혼재**한다. 설계점 고정 시 6×8↔8×8 상관 +0.746, 6×4↔6×8 +0.022.
원저자 확인을 기다리는 중이다.

- 이 문서에는 **패널별 성능을 항상 분리해서** 실었으므로 수치 자체는 정직하다.
- 다만 "전 패널 통합 Pt MAE"를 단일 지표로 강조하면 안 된다.
- 협력사가 물어보면 정직하게 말하는 편이 낫다. **"정의를 패널별로 검증 중이며,
  그래서 지표를 패널별로 분리해 보고한다"** 는 답이 오히려 신뢰를 준다.

### 3. Type 라벨 검토 범위

6×4의 900건은 사람이 검토한 라벨이다. 6×8/8×8은 분류기 출력이며 검토가 진행 중이다.
슬라이드 7-(3)에 독립 측정으로 교차 확인했다는 내용은 넣었으나,
**"전수 사람 검토"라고 말하면 안 된다.**

### 4. GointMLP / Hybrid의 Type 1 한정 지표

슬라이드 6 표에서 두 모델의 Type 1 한정 값이 비어 있다.
전체 리더보드 재생성(학습 필요)을 아직 안 돌렸다. 필요하면 돌려서 채울 수 있다.
