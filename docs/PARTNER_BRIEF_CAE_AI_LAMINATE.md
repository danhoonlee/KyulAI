## 슬라이드 1 — 출발점: PPT가 정의한 것

`Final ver2.pptx`의 Double-Double 전이하중 최적화 연구가 이 모델의 사양서다.
PPT에서 가져온 것은 다음 네 가지다.

### (1) 해석 설정

```
평판 직사각 패널 · 16 ply · ply 두께 0.0075 in
재료 Toray T800/3900S
측면 단순지지, x=0 및 x=a 고정, x=a에서 하중
```

### (2) Case 정의

```
Case2:  [[±θ₁]/[±θ₂]]₄
Case3:  [[±θ₁]/[±θ₂]/[∓θ₁]/[∓θ₂]]₂
Case4:  [([±θ₁]/[±θ₂])₂ / ([∓θ₁]/[∓θ₂])₂]
```

같은 각도 구성이라도 **두께 방향 배치가 다르면 `D*`가 달라진다.**
`A*`가 같다고 `D*`가 같지 않다 — Case 구분이 존재하는 이유다.

### (3) 예측 대상: 전이하중 Pt

비대칭 적층은 B 행렬이 0이 아니라 막-굽힘 연성이 생긴다.
**선형 고유값 좌굴해석은 이 경우 사용 가능 하중을 과대평가한다.**
따라서 모드 형상을 초기 결함으로 씨딩한 비선형 정적해석에서 전이하중을 읽는다.

**Pt가 예측 목표다.** 최대하중은 변위가 0.15 in로 고정된 조건이라
사실상 스트로크 끝점 값이다(샘플 180건 전수 확인: 180건 모두 최대값이 곡선 끝).

### (4) Type 판정 규칙

| Type | 곡선 형상 | 전이하중 정의 |
|---|---|---|
| **Type 1** | 명확한 bilinear, 전이 전후 모두 선형 | 하중 플롯 교점 |
| Type 2 | 전이 이후 구간이 휘어짐 | 하중 플롯 교점과 **u3 플롯 교점의 평균** |
| Type 3 | 크게 휨, bilinear 피팅 불가 | **u3 플롯 교점** |

Pt 기준으로 곡선이 좌우로 나뉘며 **양쪽이 선형에 가까울수록 좋은 설계**다.
Type은 3-class 분류가 아니라 **bilinear 기술이 얼마나 성립하는가의 등급**이다.

### PPT가 보고한 결과

| | 전이하중 | 준등방성 대비 |
|---|---:|---:|
| Quasi 기준 | 12,344.8 lbs | — |
| Case2 최적 | 15,880.6 lbs | +28.6% |
| Case3 최적 | 15,916.5 lbs | **+28.9%** |
| Case4 최적 | 15,908.5 lbs | +28.9% |

최적 영역은 `θ₁ ≈ 44.13°, θ₂ ≈ -49.42°` 부근.
응답면은 **네 모서리 봉우리 + 중앙 저지대**(Pattern II) 형상이다.

## 슬라이드 2 — 우리가 만들기로 한 것

PPT는 **해석으로** 최적점을 찾았다. 그 과정을 학습해서 **해석 없이** 같은 판단을 하는 것이 목표다.

```
입력:  θ₁, θ₂, Case, 패널 크기
출력:  Type + 전이하중 Pt + 하중-변위 곡선 전체
```

목적은 해석 한 건을 아끼는 것이 아니라,
**설계 공간을 전역으로 훑는 일을 가능하게 하는 것**이다.

## 슬라이드 5 — 파이프라인 감사에서 찾은 것

성능 수치보다 **이 절이 연구의 성실성을 보여준다.**

### (1) 홀드아웃 분할 누수 — 해결

**"학습 없는 최근접 조회"를 상시 비교 대상으로 리포트에 고정**해 두었다.
각도 공간에서 가장 가까운 학습 데이터를 그대로 답하는 방식이다.

> **이 행을 명확히 이기지 못한 모델은 일반화가 증명되지 않은 것이다.**

이 장치가 문제를 잡아냈다. Case2/3/4는 같은 설계의 블록 배치 차이라
**사실상 같은 라미네이트**인데(설계점 고정 시 Case 간 Pt 중앙값 차이 0.14%),
분할 키에 Case를 포함한 탓에 **홀드아웃 546행 중 537행이 학습셋에 쌍둥이를 갖고 있었다.**
조회 테이블이 모든 학습 모델을 이겼고, 그래서 발견했다.

분할 기준을 각도 쌍만으로 교정한 뒤 재측정한 것이 슬라이드 4의 수치다.
회귀 테스트로 고정해 두었다.

### (2) 패널별 Pt 정의 차이 — 원인 규명

PPT의 Type 2·3 정의는 **면외 변위(u3) 곡선을 필요로 한다.**

- **6×4** — u3 데이터가 있어 **PPT의 Type별 정의를 그대로 적용**
- **6×8 / 8×8** — u3가 없어 **하중 곡선의 꺾임점**으로 정의

검증: 각 패널의 저장값을 자체 곡선에서 꺾임점으로 재계산하면
6×8과 8×8은 **120/120 완전 일치**, 6×4는 **0/120**(중앙값 27% 차이).
정의가 다르다는 것이 확인된 사실이다.

**대응:** 패널 간 Pt 절대값을 직접 비교하지 않고 **지표를 항상 패널별로 분리해 보고**한다.
이 문서의 모든 표가 그 원칙을 따른다.

### (3) Type 라벨 — 부분 해결

6×4의 900건은 사람이 검토한 라벨이고, 6×8/8×8은 분류기 출력이다.
**Pt를 입력으로 쓰지 않고 곡선 형상만 보는 독립 측정**을 만들어
사람이 검토한 900건으로 캘리브레이션한 뒤 교차 확인했다.

| 패널 | 저장 Type 1 비율 | 독립 측정 |
|---|---:|---:|
| 6×4 | 35.7% | 35.6% |
| 6×8 | 25.2% | 24.0% |

→ **패널이 커질수록 Type 1이 줄어드는 경향은 라벨링 편향이 아니라 실제 물리다.**
8×8 일부 구간은 검토 진행 중.

### (4) 피처 중복 — 규명 후 종결

DD 문헌의 표준 좌표(라미네이션 파라미터 ξA1·ξA2, trace 정규화)를
추가 피처로 **구현해서 검증했고, 개선 없음으로 확인**되어 음성 결과를 근거와 함께 기록했다.

이유도 규명했다. Tsai-Pagano 형식으로 전개하면

```
A*₁₁ + A*₂₂ + 2A*₆₆ = 2(U₁+U₅)      ← 재료만의 함수
A*₁₂ − A*₆₆         = U₄ − U₅        ← 재료만의 함수
```

즉 **기존 피처가 이미 같은 정보를 담고 있었다.** 재진술은 정보를 더하지 않는다.

### 설계 요구조건을 명시적으로 다룬다

Type 1은 점수에 반영할 선호가 아니라 **충족해야 할 조건**이다.

```
maximize   Pt
subject to Type 1
```

조건을 만족하는 설계가 없으면 억지로 추천하지 않고 그렇다고 응답한다.
그리고 **유효 설계 비율을 함께 낸다.**

| 패널 | Type 1 충족 | 비율 |
|---|---:|---:|
| 6×4 | 321 / 900 | **35.7%** |
| 6×8 | 227 / 900 | **25.2%** |
| 8×8 | 106 / 900 | **11.8%** |

PPT가 말한 "좋은 영역은 좁다"의 정량화다.
**패널이 커질수록 쓸 수 있는 설계가 급격히 줄어든다** — 설계자가 순위표보다 먼저 알아야 할 값이다.

4. 필요한 출력이 스칼라 지표인가, 곡선/필드 전체인가?

## ⚠️ 발표 전 확인 필요 (슬라이드에 넣지 말 것)

### 1. 해석 시간 대비 속도 이득 — 숫자 없음

"FE 대비 N배"는 가장 강한 메시지지만 **해석 1건 소요시간이 기록에 없어 넣지 않았다.**
실제 값을 아시면 슬라이드 2 또는 6에 추가. 예측 쪽은 0.4초로 측정해 두었다.

> 예: "해석 1건 약 O분 → 예측 0.4초"

### 2. Pt 정의 차이 — 말할 준비를 해둘 것

슬라이드 5-(2)에 그대로 적었다. 질문받으면 그 내용을 설명하는 편이 낫다.
**"패널별로 분리해 보고한다"가 정직한 귀결이고, 그 자체가 신뢰를 준다.**
숨겼다가 드러나는 것이 가장 나쁘다.

다만 **"전 패널 통합 Pt MAE"를 단일 지표로 강조해서는 안 된다.**

### 3. Type 라벨 검토 범위

**"전수 사람 검토"라고 말해서는 안 된다.** 6×4 900건만 해당한다.
슬라이드 5-(3)의 교차 확인 내용까지가 말할 수 있는 범위다.

### 4. 대외 공개 범위

재료명(T800/3900S), 경계조건, 패널 치수, 성능 수치가 포함되어 있다.
Case 정의 수식은 공개 문헌 내용이라 문제없다고 판단했으나,
**해석 설정과 성능 수치의 공개 가능 여부는 확인이 필요하다.**

### 5. 슬라이드 3의 분량

1~7단계를 다 넣으면 슬라이드가 과밀해진다. 발표 시간에 따라:

- **짧게(10분)** — 3단계(물리 피처), 6단계(Canonical Case3 교정), 7단계(감사)만
- **길게(30분)** — 전체 + 슬라이드 5를 별도 슬라이드로 분리

**4단계(모델 후보군 전수 비교)는 표만 띄우고 넘어가도 된다.**
"단일 모델에 의존하지 않았다"는 사실 전달이 목적이다.
