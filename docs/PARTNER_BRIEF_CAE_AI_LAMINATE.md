# CAE-AI: Double-Double 라미네이트 설계

협력사 설명용 내용 정리. 우리가 **무엇을 하려는지와 왜 그 방향인지**를 전달하는 것이 목적이며,
근거는 기존에 공유한 논문과 PPT에 둔다. 슬라이드 순서대로 배열했다.

## 슬라이드 1 — 한 문장

> **같은 재료, 같은 두께, 같은 무게로 더 강한 복합재 패널을 만들 수 있다.**
> **문제는 그 설계가 어디 있는지 찾는 일이고, 우리는 그 탐색을 AI로 한다.**

## 슬라이드 2 — 출발점: 논문이 증명한 것

Vijayachandran & Waas (2021)가 확인한 내용이 이 연구의 전제다.

항공우주에서 표준으로 쓰이는 **Legacy Quad `[0/90/±45]s`**(준등방성)를 기준으로,
8-ply 대칭 적층의 각도를 최적화했을 때:

| 적층 | 좌굴하중 개선 |
|---|---|
| Legacy Quad `[0/90/±45]s` | 기준 |
| Case I `[±27]₂ₛ` 계열 | **최대 +35%** |
| Case II `[±41/∓2.5]ₛ` | **최대 +58%** |
| Case III `[±41/∓42/±6/0]ₛ` | **최대 +58%** |

여기서 결정적인 문장은 성능 수치가 아니라 다음이다.

> *"since the geometry, material and thickness remains the same,
> the total mass of the panel remains the same in all the three cases"*

**기하·재료·두께가 동일하므로 무게가 같다.**
즉 이 개선은 재료를 더 쓰거나 두껍게 해서 얻은 것이 아니라, **각도를 바꿔서 얻은 것**이다.
항공우주 구조에서 무게 증가 없는 성능 개선은 그 자체로 가치가 크다.

논문은 비대칭 적층도 다룬다. 경화 시 발생하는 초기 비평탄도를 모델링한 뒤 응답해석으로
전이하중을 구했고, 같은 각도의 대칭 적층 대비 **48.5% 감소**를 관찰했다.
다만 두께가 증가하면 연성 효과는 무시할 만해진다고 정리한다.

## 슬라이드 3 — 왜 Double-Double인가

전통적 quad 적층은 각도가 0/±45/90으로 **고정**되어 있다. 설계 자유도가 적층 순서에만 남는다.

**Double-Double(DD)** 은 `[±θ₁/±θ₂]` 두 각도쌍 블록을 반복한다.
θ₁, θ₂가 **연속 변수**이므로 설계 공간이 이산 조합에서 **연속 2차원 평면**으로 바뀐다.

`TAC vs DD.pptx`가 정리한 선정 논리도 함께 전달할 필요가 있다.
**"D11*이 가장 큰 적층이 최선"이 아니다.**

| 지표 | 의미 |
|---|---|
| `D11*` | x방향 굽힘 강성 |
| `D11*/D22*` | 방향 편중 정도 — 클수록 특정 방향에 치우침 |
| `A11*/A22*` | 면내 강성 균형 |
| `B16*, B26*` | 막-굽힘 연성 — 0이 아니면 거동이 덜 예측적 |

DD가 일반 판 구조의 안전한 기준선인 이유는 **`B* = 0`을 유지하면서 면내 강성 균형을 지킬 수 있기** 때문이다.
TAC는 연성을 의도적으로 설계에 활용할 수 있으나, 그 연성이 설계 목표의 일부일 때만 유효하고
별도 검증이 필요하다.

같은 각도 구성이라도 **두께 방향 배치 순서가 다르면 `D*`가 달라진다.**
`A*`가 같다고 `D*`가 같지 않다 — 이것이 Case 구분이 존재하는 이유다.

## 슬라이드 4 — 연구가 풀려던 문제

`Final ver2.pptx`의 연구는 논문의 결론을 **전이하중 관점에서, 16-ply DD로** 확장한다.

### 설정

- 평판 직사각 패널, 16 ply, ply 두께 0.0075 in
- 재료 Toray T800/3900S
- 측면 단순지지, x=0 및 x=a 고정, x=a에서 하중
- Case2 / Case3 / Case4 — 같은 각도 구성의 서로 다른 블록 배치

```
Case2:  [[±θ₁]/[±θ₂]]₄
Case3:  [[±θ₁]/[±θ₂]/[∓θ₁]/[∓θ₂]]₂
Case4:  [([±θ₁]/[±θ₂])₂ / ([∓θ₁]/[∓θ₂])₂]
```

### 왜 좌굴하중이 아니라 전이하중인가

비대칭 적층에서는 B 행렬이 0이 아니어서 막-굽힘 연성이 발생한다.
**선형 고유값 좌굴해석은 이 경우 사용 가능 하중을 과대평가한다.**

따라서 다음 절차를 쓴다.

```
1. 고유값 좌굴해석으로 모드 형상을 얻고
2. 모드를 초기 기하 결함으로 스케일링해 씨딩하고
3. 비선형 정적해석을 수행하고
4. 하중-변위 곡선에서 전이하중을 읽는다
```

**전이하중(Pt)이 실제 거동에 가깝다.** 이것이 예측 목표다.

### 결과 (PPT 보고값)

| | 전이하중 | 준등방성 대비 |
|---|---:|---:|
| Quasi 기준 | 12,344.8 lbs | — |
| Case2 최적 | 15,880.6 lbs | **+28.6%** |
| Case3 최적 | 15,916.5 lbs | **+28.9%** |
| Case4 최적 | 15,908.5 lbs | **+28.9%** |

비용함수 관점(좌굴 70% / 굽힘강성 30% 가중)에서도 준등방성 2.283682 대비
Case2 최적 2.998788로 **+31.3%**.

**최적 영역은 `θ₁ ≈ 44.13°, θ₂ ≈ -49.42°` 부근에 반복적으로 나타난다.**

## 슬라이드 5 — 그런데 여기서 막힌다

위 결과는 **설계 공간을 해석으로 훑어서** 얻었다. 그리고 그것이 한계다.

### 응답면이 단순하지 않다

PPT는 Case를 두 패턴으로 나눈다.

- **Pattern I** (Case1, Case5) — twin-ridge / center-basin
- **Pattern II** (Case2, Case3, Case4) — **네 모서리 봉우리, 중앙 저지대**

Pattern II에서 좋은 영역은 `θ₁ = θ₂ = 0` 에서 멀리 떨어져 있고,
±45도 계열 조합이 성능을 지배한다.
**국소 탐색이나 직관으로는 찾기 어려운 형상이다.**

### 곱해지는 차원

| 축 | 경우의 수 |
|---|---|
| θ₁ | 연속 |
| θ₂ | 연속 |
| Case | 3 (PPT 기준 Case1/Case5까지 5) |
| 패널 크기 | 설계마다 다름 |
| 재료 | 확장 시 증가 |

각 조합마다 **결함 씨딩 + 비선형 정적해석**이 필요하다.
설계 공간을 넓힐수록 해석 비용이 조합적으로 증가한다.

> **연구는 "DD가 준등방성보다 좋다"를 증명했다.**
> **남은 문제는 "주어진 조건에서 그 최적점을 어떻게 찾을 것인가"다.**

## 슬라이드 6 — 우리가 하려는 것

**해석 결과를 학습해서, 해석을 돌리지 않고 거동을 예측하는 대리모델을 만든다.**

```
[1] 고충실도 해석          결함 씨딩 비선형 정적해석
        ↓
[2] 물리 기반 피처          CLT A/B/D 행렬, 두께 정규화,
        ↓                  이방성·대칭성 기술자, 패널 기하
[3] 대리모델               Type + Pt + 하중-변위 곡선 전체
        ↓
[4] 설계 공간 탐색          요구조건 충족 후보만 순위화
        ↓
[5] 서비스                 REST API + 웹 UI
```

목적은 **해석 한 건을 아끼는 것이 아니다.**
원래는 시도조차 못 하던 **설계 공간 전역 탐색을 가능하게 하는 것**이다.

### 무엇을 예측하는가

| 출력 | 설명 |
|---|---|
| **전이하중 Pt** | 핵심 목표. 재료가 거동을 바꾸기 시작하는 지점 |
| **거동 유형 Type** | bilinear 기술이 얼마나 잘 성립하는가의 등급 |
| **하중-변위 곡선** | 스칼라가 아니라 곡선 전체 (1,001점) |

**최대하중은 목표가 아니다.** 변위가 0.15 in로 고정된 조건이므로
최대하중은 사실상 스트로크 끝점의 하중값이다. 샘플 180건 전수 확인 결과 180건 모두
최대값이 곡선 끝에 있었다.

### Type 정의 (PPT 기준)

| Type | 곡선 형상 | 전이하중 정의 |
|---|---|---|
| **Type 1** | 명확한 bilinear, 전이 전후 모두 선형 | 하중 플롯 교점 |
| Type 2 | 전이 이후 구간이 휘어짐 | 하중 플롯 교점과 **u3 플롯 교점의 평균** |
| Type 3 | 전반적으로 크게 휨, bilinear 피팅 불가 | **u3 플롯 교점** |

Pt를 기준으로 곡선이 좌우로 나뉘며, **양쪽이 모두 선형에 가까울수록 좋은 설계**다.
따라서 Type 1이 설계 요구조건이다.

## 슬라이드 7 — 현재까지 구축한 것

| 항목 | 현황 |
|---|---|
| 학습 데이터 | 해석 **2,700건** (설계점 300 × Case 3 × 패널 3) |
| 패널 | 6×4, 6×8, 8×8 in |
| 곡선 해상도 | 건당 1,001점 |
| 예측 대상 | Type, Pt, 하중-변위 곡선 전체 |
| 응답 속도 | 단건 약 **0.4초** (곡선 포함, 엔드투엔드) |
| 서비스 | `ai.imperialax.com` 외 2개 도메인 운영 중 |

### 물리 피처의 효과

θ₁, θ₂를 그대로 넣지 않고 고전적층이론으로 재인코딩한다. 정량적 효과:

| 입력 | Pt MAE | Type 1 구간 Pt MAE | Type 정확도 |
|---|---:|---:|---:|
| θ₁, θ₂, Case, 패널 (원시) | 467.17 | 643.12 | 0.8962 |
| **CLT 물리 피처** | **200.79** | **176.93** | **0.9581** |

**물리를 좌표계로 넣는 것만으로 Pt 오차 2.3배, 설계 유효 구간에서 3.6배 개선된다.**
이것이 범용 ML이 아니라 CAE-AI인 이유다.

### 유효 설계 비율

PPT가 말한 "좋은 영역은 좁다"를 정량화하면:

| 패널 | Type 1 충족 | 비율 |
|---|---:|---:|
| 6×4 | 321 / 900 | **35.7%** |
| 6×8 | 227 / 900 | **25.2%** |
| 8×8 | 106 / 900 | **11.8%** |

**패널이 커질수록 쓸 수 있는 설계가 급격히 줄어든다.**
설계자에게 순위표보다 먼저 필요한 정보이므로 API 응답과 화면에 이 값을 함께 낸다.

## 슬라이드 8 — 방법론적 태도

성능 수치보다 **그 수치를 믿을 수 있게 만드는 장치**를 함께 설명한다.

### (1) 학습 없는 베이스라인을 상시 비교 대상으로 둔다

리포트에 "최근접 조회" 행이 영구 고정되어 있다.
학습을 전혀 하지 않고 각도 공간에서 가장 가까운 학습 데이터로 답하는 방식이다.

> **이 행을 명확히 이기지 못한 모델은 일반화가 증명되지 않은 것이다.**

실제로 이 장치가 문제를 잡아냈다. Case2/3/4는 같은 설계의 블록 배치 차이라
사실상 같은 라미네이트인데(설계점 고정 시 Case 간 Pt 중앙값 차이 0.14%),
초기 데이터 분할이 Case를 키에 포함해 **홀드아웃 546행 중 537행이 학습셋에 쌍둥이를 갖고 있었다.**
조회 테이블이 모든 학습 모델을 이겼고, 그래서 발견했다. 분할 기준을 교정한 뒤 재측정했다.

### (2) 요구조건과 목적함수를 분리한다

Type 1은 점수에 반영할 선호가 아니라 **충족해야 할 조건**이다.
Pt가 높다고 Type 3 설계가 수용 가능해지지 않는다.

```
maximize   Pt
subject to Type 1
```

조건을 만족하는 설계가 없으면 억지로 추천하지 않고 그렇다고 응답한다.

### (3) 예측에 신뢰도를 동반한다

보간/외삽 판정, 인근 데이터 밀도, Pt 구간 추정이 함께 나간다.
학습 범위 밖 패널 입력은 차단하고, 학습에 없는 조합은 신뢰도를 상한 처리한다.

### (4) 가설도 측정해서 기각한다

DD 문헌의 표준 좌표(라미네이션 파라미터 ξA1·ξA2, trace 정규화)를 추가 피처로 구현해 검증했고,
**개선 없음**으로 확인되어 그 음성 결과를 근거와 함께 기록했다.
이유도 규명했다 — Tsai-Pagano 형식으로 전개하면 기존 피처가 이미 같은 정보를 담고 있다.

## 슬라이드 9 — 방향성

### 라미네이트

1. **Case 확장** — 현재 Case2/3/4. PPT의 Pattern I(Case1, Case5)까지 확장
2. **패널 연속화** — 현재 3종 → 연속 치수 대응
3. **재료 확장** — 현재 단일 재료. trace 정규화가 재료 간 전이의 경로가 될 수 있음
4. **독립 솔버 교차검증** — OpenRadioss 툴체인 구축 완료. 최적화가 제안한 상위 설계를
   다른 솔버로 검증하는 루프
5. **논문 범위와의 접속** — 논문은 좌굴하중과 이축하중(1:1, 2:1)을 다룬다.
   현재 단축 전이하중 중심이므로 이축 조건은 확장 여지

### CAE-AI 플랫폼으로서

라미네이트는 **첫 번째 도메인**이다. 구조는 도메인 독립적이다.

```
고충실도 해석 → 물리 기반 피처 → 대리모델 → 제약 내 탐색 → 서비스
```

사출성형에 같은 구조를 적용해 별도 서비스로 운영 중이다.
협력사의 해석 자산이 있다면 동일 파이프라인을 얹을 수 있다.

## ⚠️ 발표 전 확인 필요 (슬라이드에 넣지 말 것)

### 1. 해석 시간 대비 속도 이득 — 숫자 없음

"FE 대비 N배"는 가장 강한 메시지지만 **해석 1건 소요시간이 기록에 없어 넣지 않았다.**
실제 값을 아시면 슬라이드 1 또는 7에 추가. 예측 쪽은 0.4초로 측정해 두었다.

> 예: "해석 1건 약 O분 → 예측 0.4초"

### 2. 패널별 Pt 정의 차이 — 말할 준비를 해둘 것

Type 2·3의 전이하중 정의에는 **면외 변위(u3) 곡선이 필요하다**(슬라이드 6 표).

- 6×4 데이터에는 u3가 있어 **PPT의 Type별 정의를 그대로 적용**했다.
- 6×8 / 8×8 데이터에는 u3가 없어 **하중 곡선의 꺾임점**으로 정의했다.

검증 결과: 6×8/8×8은 자체 곡선에서 꺾임점을 재계산하면 **120/120 완전 일치**,
6×4는 0/120 (중앙값 27% 차이). 즉 **정의가 다른 것이 확인된 사실**이다.

**대응 방침:** 패널 간 Pt 절대값을 직접 비교하지 않고, **지표를 항상 패널별로 분리해 보고한다.**
이 문서의 모든 표가 그 원칙을 따른다. 질문을 받으면 위 내용을 그대로 설명하는 편이 낫다.
숨겼다가 드러나는 것이 가장 나쁘다.

### 3. Type 라벨 검토 범위

6×4의 900건은 사람이 검토한 라벨이다. 6×8/8×8은 분류기 출력이며 검토 진행 중이다.
독립적인 곡선 형상 측정으로 Type 1 비율 경향은 교차 확인했으나
(6×4 독립측정 35.6% vs 저장값 35.7%, 6×8 24.0% vs 25.2%),
**"전수 사람 검토"라고 말해서는 안 된다.**

### 4. 대외 공개 범위

재료명(T800/3900S), 경계조건, 패널 치수, 성능 수치가 포함되어 있다.
논문 인용 내용과 Case 정의 수식은 공개 문헌이므로 문제없다고 판단했으나,
**해석 설정과 성능 수치의 공개 가능 여부는 확인이 필요하다.**

### 5. 논문 수치 인용 시 주의

슬라이드 2의 +35% / +58%는 **논문의 8-ply 대칭 적층 좌굴하중** 결과다.
슬라이드 4의 +28.9%는 **PPT의 16-ply DD 전이하중** 결과다.
**서로 다른 연구의 다른 지표이므로 합산하거나 혼용하면 안 된다.**
