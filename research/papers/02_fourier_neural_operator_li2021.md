**Venue:** ICLR 2021

**Domain:** Neural Operators / Surrogate Modeling

## Problem Formulation

Classical neural networks learn point-to-point mappings and must be retrained for each new discretization. **Neural operators** instead learn mappings between function spaces: `G: A → U` where A is the space of input functions (e.g., initial conditions, boundary conditions, material coefficients) and U is the solution function space. This is the correct abstraction for PDE surrogate modeling — the operator is discretization-invariant.

The Fourier Neural Operator (FNO) parameterizes the integral kernel operator directly in **Fourier space**, enabling global spectral mixing at each layer while remaining O(n log n) in computational cost.

## Model Architecture

```
Input: discretized function a(x) on grid (e.g., material coefficient field)
  ↓
Lifting layer: linear projection to higher-dim channels
  ↓
L × Fourier layers:
  each layer = FFT → truncate to k_max modes → learnable complex weights W → IFFT
             + local linear transform (W_local · v) [bypassing spectral part]
             + activation σ
  ↓
Projection layer: linear to output channels
Output: discretized solution u(x)
```

Key parameters:
- `k_max`: number of Fourier modes retained (controls spectral resolution)
- `d_v`: channel width (representation capacity)
- `L`: number of Fourier layers (depth)

## Training Strategy

- **Supervised learning** on (input_function, solution_function) pairs generated by classical solvers
- Loss: relative L² error over the output field
- Optimizer: Adam with cosine annealing
- No physics loss terms required (purely data-driven by default; PINO variant adds PDE residuals)
- **Key property:** Train once on a coarse grid; evaluate at arbitrary resolutions (zero-shot super-resolution)

## Dataset Characteristics

| PDE | Training Pairs | Grid | Notes |
|-----|---------------|------|-------|
| Burgers' equation | 1,000 | 1D, 8192 pts | Viscous shock dynamics |
| Darcy flow | 1,000 | 2D, 421×421 | Subsurface flow in random porous media |
| Navier-Stokes | 1,000 | 2D, 64×64 | Turbulent flow, time-dependent |

## Reported Metrics and Results

- **Darcy flow:** relative L² = 0.0108 (vs 0.0244 for best prior ML method — 2.3× improvement)
- **Navier-Stokes (turbulent):** FNO is **the first ML method to accurately model turbulent flow**
- **Speed:** 1,000× faster than classical FEM solvers at inference
- **Zero-shot super-resolution:** model trained at 64×64 evaluated at 256×256 — minimal accuracy loss
- **Discretization invariance:** same model weights used across grid resolutions

## Limitations and Gaps

- **Regular grids only (standard FNO):** operates on uniform Cartesian grids — cannot natively handle unstructured FE meshes
- Requires large paired training datasets (simulation runs); performance degrades with very few training pairs (<100)
- Spectral truncation at k_max means behavior far from training distribution requires care
- Standard FNO does not handle complex geometries directly (Geo-FNO and GNOT extensions address this)
- No built-in uncertainty quantification

## Extensions Relevant to KyulAI

- **Geo-FNO / GNOT:** extends FNO to arbitrary geometries via learned deformation mappings
- **PINO (Physics-Informed Neural Operator):** adds PDE residual loss, enabling training with fewer simulation pairs
- **FNO for composites autoclave curing** (see Paper 03): directly applied to thermo-chemical curing PDEs with process parameter conditioning

## Relevance to KyulAI

**Very high.** FNO is the most practical operator learning method for KyulAI's field-level simulation surrogates:
- Abaqus stress/strain fields, Moldex3D flow fronts, AniForm fiber angle fields are all PDE solution fields
- FNO can learn the operator mapping (process params, material params) → field response
- Zero-shot super-resolution means training on coarse meshes, inference on fine meshes
- 1000× speedup enables real-time design exploration and uncertainty quantification via ensembles
- **Geo-FNO or GNOT** should be used for irregular composite part geometries
