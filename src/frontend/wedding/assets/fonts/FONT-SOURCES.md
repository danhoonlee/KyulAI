# Wedding font assets

These self-hosted subsets remove the invitation's runtime dependency on Google Fonts.
They were generated from the upstream Google Fonts files and contain the characters used by the wedding pages.
Unknown guestbook characters fall back to the device's Korean system fonts.

- Gowun Batang: Google Fonts `ofl/gowunbatang`
- Cormorant Garamond: Google Fonts `ofl/cormorantgaramond`
- Pinyon Script: Google Fonts `ofl/pinyonscript`

Each family is distributed under the SIL Open Font License included beside these files.
