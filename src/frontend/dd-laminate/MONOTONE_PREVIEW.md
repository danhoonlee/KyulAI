# ImperialAX Laminate Monotone Preview

## Status

- Review concept only
- Not connected to the production route
- Existing `index-v2.html`, `index-v2.ko.html`, and `styles-v2.css` remain unchanged

## Preview pages

- Korean: `index-monotone.ko.html`
- English: `index-monotone.html`

The preview pages reuse `auth-gate.js` and `app-v2.js`, so the forms, element IDs, and application behavior stay aligned with the current v2 screen.

## Visual direction

The concept follows `ImperialAX_PPT_Template_Monotone.pptx`:

- near-black, white, and warm-gray surfaces
- official ImperialAX logo and large low-opacity mark
- square panels, thin rules, and almost no elevation
- typography and spacing carry hierarchy instead of accent color
- charts and the live laminate illustration are displayed in grayscale
- semantic error color remains available for accessibility

## Review points

1. Should the black hero remain this tall, or become a compact application header?
2. Should the research-purpose section stay as a black/white split, or move below the main prediction workspace?
3. Should charts remain fully monochrome, or use one restrained signal color for Pt and selected curves?
4. If approved, should this replace v2 or remain as a selectable theme?
