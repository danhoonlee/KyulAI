# Laminate Forecast Geometry Training Report

- Dataset: `data/datasets/DD_cases_2_3_4_geometry_v1`
- Samples: `1800`
- Feature set: `theta_physics_geometry_v1`
- Input features: `40`
- Panel sizes: `6x4` and `6x8`
- Cases: `Case2`, `Case3`, `Case4`

## Model Comparison

| Model | Type accuracy | Macro F1 | Pt MAE (kips) | Max force MAE (kips) | Curve norm RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| Geometry ML / Tree | 0.9561 +/- 0.0106 | 0.9511 +/- 0.0150 | 316.31 +/- 49.28 | 315.11 +/- 17.04 | 0.00572 +/- 0.00087 |
| Geometry DL / GointMLP | 0.9494 +/- 0.0097 | 0.9484 +/- 0.0100 | 823.04 +/- 93.57 | 1261.57 +/- 246.16 | 0.02100 +/- 0.00217 |

## Interpretation

- Geometry ML is the stronger deployment default for Pt, max force, and curve prediction.
- Geometry DL is now available as a neural comparison model, but it should be treated as a secondary research model until more panel-size-diverse data or RTX-based hyperparameter tuning is added.
- Both models use panel-size descriptors, so the same theta/case input can produce different predictions for `6x4` and `6x8`.

## Caveat

The `6x8` Type labels were generated by the existing curve classifier from the new CSV curves, not manually reviewed. The combined model is useful for internal screening and UI validation, but research-grade geometry generalization should be checked with manually reviewed labels or a geometry-held-out validation set.
