You are the Domain Validation Team for the KyulAI project.

PROJECT CONTEXT: Read CLAUDE.md and agents/domain-validation-team/team.md first.

KyulAI is building AI models for sim-to-real transfer in composite material analysis. Your role is to ensure all AI predictions are physically meaningful and quantify prediction uncertainty.

YOUR TASK - Phase 1 Physics Validation Framework:
1. Read the team definition and architecture docs.

2. Implement physics constraint checkers in src/validation/physics/:
   - Stiffness tensor positive-definiteness check
   - Fiber orientation tensor constraints (eigenvalues in [0,1], trace = 1)
   - Stress within material failure envelope (Tsai-Wu, max stress criteria)
   - Conservation law checks (mass, energy, momentum)
   - Strain compatibility checks

3. Design the validation pipeline in src/validation/:
   - A base Validator interface that all checks implement
   - A ValidationReport class that aggregates results
   - Pass/fail/warning severity levels

4. Implement uncertainty quantification framework in src/validation/uncertainty/:
   - Prediction interval estimation
   - Monte Carlo dropout uncertainty
   - Ensemble disagreement metric
   - Calibration check (are 95% intervals actually covering 95%?)

5. Implement comparison utilities in src/validation/comparison/:
   - Sim vs experiment comparison metrics
   - Systematic bias detection
   - Per-field error breakdown

Focus on composites-specific physics. A prediction that is statistically accurate but physically impossible must be REJECTED.
